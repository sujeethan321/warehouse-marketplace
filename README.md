# Shared Warehouse Marketplace

This repository contains a full-stack workspace for a shared warehouse marketplace application with a React frontend and Node.js backend.

## Project Structure

- `frontend/` – React + Vite app for user interfaces
- `backend/` – Express API server and business logic
- `database/` – SQL schema and sample seed data
- `docs/` – planning, API docs, and design notes

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
